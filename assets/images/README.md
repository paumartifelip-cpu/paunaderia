### 💡 ¿Cómo ir poniendo las fotos nuevas?
1. **Simplemente envíame la imagen por el chat** y dime a qué pan corresponde.
2. Yo me encargaré de colocarla en esta carpeta con el nombre exacto y actualizar automáticamente el catálogo.
3. Para los productos que aún no tengan imagen física, el sistema muestra un **placeholder artesanal elegante con icono y badge**, para que la página siempre luzca impecable.
